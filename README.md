### About the Experiment 

This experiment focuses on performing data preprocessing and feature engineering on the Titanic dataset. It covers essential techniques such as handling missing values, normalizing numerical features, encoding categorical variables, creating new meaningful features, and visualizing the data. These steps are critical for improving data quality and preparing it for effective machine learning model development.
